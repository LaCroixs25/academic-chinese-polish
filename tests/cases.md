# academic-chinese-polish 测试用例

每次修改 SKILL.md 后，用新的对话逐条调用 skill，按"检查点"打勾。

## 1 数值与百分点
原文：实验结果表明，新模型的准确率从82.1%提升到了85.3%，提升了3.2%，效果非常明显。
检查点：
- [ ] 82.1% 与 85.3% 原样保留
- [ ] "提升了3.2%"被指出应为"3.2 个百分点"，且改动在说明中列出，不静默改
- [ ] "非常明显"未改成"显著"，也未弱化成"较为明显"

## 2 相关与因果
原文：问卷数据显示，每天使用手机超过5小时的学生成绩普遍较低，说明手机使用导致了学习成绩下降。
检查点：
- [ ] 指出由相关推出因果的证据缺口
- [ ] 成稿未擅自删掉或改写因果结论
- [ ] 指出"成绩普遍较低"缺少比较对象

## 3 口语改书面语
原文：我们这个研究其实主要就是想看看，社区养老这块到底存在哪些问题，然后给出一些建议。
检查点：
- [ ] 去掉"其实""就是""这块""到底"等口语
- [ ] 未加"填补空白""具有重要意义"等拔高措辞

## 4 引用范围
原文：已有研究表明，短视频使用与注意力下降有关[3]，并且这种影响在青少年中更明显，也会影响睡眠质量[5]。
检查点：
- [ ] "有关"未改成"导致"
- [ ] [3]、[5] 的位置与覆盖范围不变（未拆成两句使 [5] 只管睡眠）
- [ ] "也会影响睡眠质量"的主语歧义被保留或列为待确认，未擅自补主语

## 5 降重请求
原文：请帮我降重：随着互联网技术的快速发展，电子商务已经成为人们日常生活中不可或缺的一部分。
检查点：
- [ ] 改写了表达
- [ ] "不可或缺"的强度保留（未弱化成"重要"）
- [ ] 未承诺降低重复率，未用机械同义替换或插入字符

## 6 术语、的地得
原文：本文采用了Precision和Recall作为评价指标，实验发现模型的精确率达到了0.91，准确率也很高，并且模型能够快速的收敛。
检查点：
- [ ] "快速的收敛"改为"快速地收敛"
- [ ] "精确率"与"准确率"未合并；指出"准确率"不在所列指标中，待确认
- [ ] 未自行给 Recall 补中文译名，未给"准确率"补数值
