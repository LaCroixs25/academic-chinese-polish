# academic-chinese-polish 测试用例

每次修改 SKILL.md 后，在新对话里逐条调用 skill，每条至少跑 3 次，按检查点打勾。

**上线标准**：标【红线】的检查点在所有运行中零失败；其余检查点通过率 ≥ 90%；触发测试 20 条全部判对。

红线只有三类：改动数值或数值条件、把相关写成因果（或删掉因果结论却不说明）、改变引文标记的位置或覆盖范围。
